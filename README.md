# 🤖 Jarvis-CLI

Personal Terminal Executive Assistant powered by **Groq API** with Tool Calling, SQLite Memory, and Colorama UI.

## ✨ Features
- 🕐 Real-time clock & date
- 🧮 Smart calculator (math expressions)
- 📝 Notes management (CRUD)
- ✅ Todo list tracker
- 💻 System information
- 🧠 SQLite-powered conversation memory
- 🎨 Colorful terminal UI

## 🛠️ Tech Stack
- Python 3.10+
- Groq API (LLM Inference)
- SQLite3 (Memory Storage)
- Colorama (Terminal UI)

## 🚀 Quick Start
```bash
git clone https://github.com/mardhikaramdhoni-ops/tobblez.git
cd jarvis-cli
pip install -r requirements.txt
cp .env.example .env  # Tambahin GROQ_API_KEY lu
python main.py
